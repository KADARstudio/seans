# Seans — granice projektu

Wszystkie operacje zapisu, testy, dane i publikacja Seansu wyłącznie w repozytorium KADARstudio/seans (ID 1376451444). Przed zapisem sprawdź repozytorium, gałąź i bieżącą zawartość. Nie używaj repozytoriów innych projektów, ich serwerów, baz ani sekretów. Nie kopiuj kluczy dostępu. Nie wykonuj force push. Nie twierdź, że aplikacja jest opublikowana bez sprawdzenia publicznego adresu.

Dane o ofertach muszą dotyczyć Polski i abonamentów FLATRATE. Pokaż datę rzeczywistego pobrania. Nie zamieniaj błędu źródła w wymyślone oferty. Integracja prototypowa wymaga licencji / wspieranego API przed komercyjnym wydaniem. Wybór filmu, kliknięcie platformy i potwierdzone obejrzenie to oddzielne zdarzenia.
